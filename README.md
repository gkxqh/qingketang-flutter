# 晴课堂（Sunny Classroom）

面向雨课堂的轻量级第三方 Flutter 客户端，提供课堂实时同步、随堂作答与草稿防丢、课件预加载与离线导出、以及全课程作业与任务提醒等功能。

## 功能特性

- **多节点登录与会话管理**
  - 支持雨课堂通用版、长江雨课堂、荷塘雨课堂 Pro、黄河雨课堂四个服务器节点
  - 支持微信扫码登录、手机号 + 短信验证码、手机号 + 密码登录及腾讯防水墙验证码 WebView
  - 使用系统安全存储保存登录会话与课堂 Token
- **课堂实时同步与交互**
  - 实时接收翻页、发题、延时、收题、通知与点名事件
  - 支持常规开课自动签到（立即签到 / 询问 / 仅提醒 / 关闭），**不支持动态码签到**
  - 支持单选、多选、投票、填空与主观（含七牛云图片上传）的习题作答，以及超时补交
  - 支持未发布习题预选答案、本地草稿持久化与可配置延迟（0–30 秒）自动提交，但目前存在后台保活问题
- **课件浏览与离线导出**
  - 课件列表、图片流浏览、跟随老师翻页与全屏缩放
  - 支持课件预加载与一键导出，可自定义导出目录，可选择导出方式：多页标准 PDF/离线交互式 HTML/逐页图片
- **作业与任务中心**
  - 聚合全部已选课程的作业与试卷活动，按紧急程度与截止时间排序
  - 区分未提交、已提交、已批改与已逾期状态，支持内置 WebView 直达作答
- **个性化与实用设置**
  - 完整深色模式（跟随系统 / 浅色 / 深色）
  - 自定义首页昵称与头像、清除 WebView 缓存等

## 工程结构

```text
lib/
  core/        # Cookie 等基础工具
  models/      # 课堂、课件、题目、作业、会话与状态机模型
  screens/     # 首页、登录、课堂、作业中心、设置与关于等页面
  services/    # API 客户端、WebSocket、缓存、导出与前台服务
  widgets/     # 答题面板、提示卡片等通用组件
```

## 本地构建与测试

```bash
flutter pub get
dart analyze
flutter test
```

按架构打包 Release APK（推荐 `arm64-v8a` 真机包）：

```bash
flutter build apk --release --split-per-abi
```
